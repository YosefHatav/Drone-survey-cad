# רחפן ← שרטוט (Drone Survey CAD)

כלי למשרד מדידות: מתצלומי רחפן לשרטוט מלא שנפתח ונערך באוטוקאד (DXF).

## תהליך העבודה

1. **פרויקט חדש.** ברירת המחדל היא רשת ישראל החדשה (ITM, EPSG:2039) וקנ"מ 1:250.
2. **נתונים.** אפשר להעלות אורתופוטו, DSM ו־DTM (GeoTIFF) מכל תוכנת עיבוד: Pix4D, DJI Terra, Metashape, ODM.
   - קבצים במערכת קואורדינטות אחרת (למשל UTM 36N) מומרים אוטומטית ל־ITM.
   - אפשר גם לשלוח תמונות גולמיות לעיבוד ב־OpenDroneMap (ראו "התקנה עם עיבוד תמונות").
3. **בקרה ודיוק.** טוענים קובץ נקודות בפורמט `שם,E,N,H[,gcp|check]`.
   - המערכת מחשבת dH לכל נקודה, ובלחיצה על "סמן" גם את dE ו־dN.
   - מוצגים RMSE וממוצע dH, בנפרד לנקודות בקרה ולנקודות ביקורת.
   - "החל תיקון גובה" מזיז את כל הגבהים לפי הממוצע. זה מתקן את ההפרש בין גובה אליפסואידי לגובה אורתומטרי, או הטיה של העיבוד.
4. **שרטוט.** בוחרים קוד (אבן שפה, מבנה, עמוד וכו') ולוחצים על האורתופוטו.
   - הגובה של כל קודקוד נדגם אוטומטית (אינטרפולציה בילינארית).
   - קודי קרקע נדגמים מה־DTM, וקודים של "גג" ו"ראש קיר" נדגמים מה־DSM.
   - קיצורי מקשים: 1–9 לבחירת קוד, Esc לביטול, Enter או לחיצה כפולה לסיום קו, Ctrl+Z לביטול פעולה, E לעריכת קודקודים, Del למחיקה. ההצמדה (Snap) לקודקודים קיימים פעילה.
5. **רומים וקווי גובה.**
   - רשת רומים וקווי גובה (ראשיים ומשניים) בתוך גבול אזור העבודה (קוד AREA).
   - לא נוצרים קווים ורומים בתוך מבנים.
6. **ייצוא.**
   - **DXF:** שכבות TOPO-* ו־SURV-* עם צבעים ותיאור בעברית; בלוקים לסימבולים עם תכונה ELEV; קווים כפוליליין תלת־ממדי; קווי גובה כ־LWPOLYLINE עם Elevation (מתאים לבניית משטח ב־Civil 3D); רשת קואורדינטות; טבלת כותרת; חץ צפון.
   - **ZIP:** קובץ ה־DXF, אורתופוטו JPG עם קובץ JGW שמקושר לשרטוט, קובץ נקודות PNEZD וקובץ דוח דיוק.

## התקנה

```bash
pip install -r requirements.txt
./run.sh            # ב-Windows: run.bat
# פותחים http://localhost:8000
```

נתוני דוגמה לניסיון: `python scripts/make_sample.py sample_data`

### התקנה עם עיבוד תמונות (OpenDroneMap)
```bash
docker compose up    # מפעיל את האפליקציה ושרת NodeODM
```
מומלץ לצרף קובץ `gcp_list.txt` בפורמט ODM כשהכותרת היא `EPSG:2039`, כדי שהתוצרים ייצאו ישירות ב־ITM ובגובה אורתומטרי.

## התאמה לתבנית המשרד ולתקן
- **תבנית משרד (לשונית "תבנית ותקן"):** טוענים קובץ DXF של המשרד. אם מותקן [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) החינמי, אפשר לטעון גם DWG.
  - הייצוא נבנה בתוך התבנית, כך שהשכבות, הבלוקים וסגנונות הטקסט שלה נשמרים.
  - הקודים ממופים אוטומטית לשכבות לפי שם ותיאור, ואפשר לתקן את המיפוי בטבלה.
  - סימבולים מוכנסים כבלוקים של המשרד, ותכונת הגובה (ELEV, Z, H, HEIGHT, גובה או רום) מתמלאת אוטומטית.
- **מצב תאימות מבא"ת / מפרט מיפוי לאומי:** מיישם את כללי השרטוט מתוך [הנחיות מבא"ת למודדים](https://www.gov.il/BlobFolder/policy/mavat_measurement/he/guidelines_surveyors.pdf):
  - אין ישויות POINT, TEXT, MTEXT או CIRCLE, וכל כיתוב נמצא בתוך בלוק עם תכונה.
  - שכבה 0 ריקה, והצבעים ByLayer.
  - גופן HEBTXT, ודיוק יחידות של 6 ספרות.
  - הערך ‎-444 מסמן נתון חסר.
  - מסגרת, כותרת וחץ צפון נמצאים בשכבת התעלם (ברירת מחדל: 1201).
  - שמות השכבות המספריים של המפרט נלקחים מקובץ התבנית ([מפרט מיפוי לאומי, מפ"י](https://www.mapi.gov.il/ProfessionalInfo/Pages/INMS.aspx)).
- **קובץ קודים:** את טבלת הקודים והשכבות אפשר גם להחליף בקובץ JSON. מגדירים את מיקום הקובץ במשתנה הסביבה `DSC_CODES_FILE`.
- **DWG:** כש־ODA File Converter מותקן, חבילת ה־ZIP כוללת גם קובץ DWG.

## מגבלות ידועות (MVP)
- אין עדיין חילוץ קווים אוטומטי (AI). השרטוט נעשה ידנית, וזה השלב הבא במפת הדרכים.
- גובה מתחת לצמחייה צפופה לא אמין אם אין DTM.
- כיתובים בעברית ב־DXF מוגדרים בגופן David או Arial. כדאי לבדוק את התצוגה בגרסת האוטוקאד של המשרד.

## אתר בדומיין משלך (שרת פרטי)
1. שוכרים שרת Ubuntu (VPS) עם 4GB זיכרון ומעלה, ומפנים את רשומת ה־A של הדומיין לכתובת ה־IP שלו.
2. מתחברים לשרת ב־SSH ומריצים:
```bash
curl -fsSL https://raw.githubusercontent.com/YosefHatav/Drone-survey-cad/main/deploy/install.sh | bash -s -- survey.example.co.il  הסיסמה-שלך
```
הסקריפט מתקין Docker, את האפליקציה, את שרת העיבוד OpenDroneMap ותעודת HTTPS אוטומטית (Caddy). לעדכון גרסה מריצים `/opt/drone-survey-cad/deploy/update.sh`.
